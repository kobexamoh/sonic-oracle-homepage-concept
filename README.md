# Sonic Oracle — Homepage Concept
A homepage design exploration for [Sonic Oracle](https://sonicoracle.music), a music discovery app for Tidal, Qobuz, and YouTube Music.

Static HTML/CSS, no build step, no framework.

## Local preview

Open `index.html` directly in a browser, or serve it:

```bash
npx serve .
```

## Structure

- `index.html` — page markup
- `style.css` — styling
