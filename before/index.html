Behind the Scene

Built on real listening data

Sonic Oracle pulls from publicly available listening data, cross-references artist relationships, and applies a proprietary scoring algorithm to surface artists automated playlists miss. The result is a discovery map built on what real people listen to, not on what an algorithm thinks you should hear.

The Adventure Dial

Go deeper than any algorithm
will take you

Three depths of discovery, one dial. Essential surfaces the core connections every fan should know. Balanced pulls in deeper cuts from the same world. Adventurous breaks the walls down, crossing genres, decades, and scenes to find artists no playlist has ever handed you. Run the same seed twice on Adventurous and get different results each time.
